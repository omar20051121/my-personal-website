# 🌐 Personal Portfolio Website

This is a multi-page personal portfolio website built using HTML, CSS, JavaScript, and Bootstrap. It presents my academic journey, personal development, technical interests, and future goals in Computer Science in a structured and interactive way.

The website is designed to go beyond a traditional CV by offering a deeper, more dynamic presentation of my skills, mindset, and learning journey.


## ✨ Overview

This website goes beyond a traditional CV by showcasing my personal growth, mindset, and technical development. It is designed to clearly present who I am as a Computer Science student and how I continuously improve my skills through learning and practical experience.

---

## 🚀 Features

- Multi-page structure:
  - Home (personal story & background)
  - Interests & hobbies
  - Projects & experience (under development)
  - Future goals & contact
- Interactive JavaScript functionality:
  - Read more / read less toggle
  - Expandable sections (show/hide content)
- Clean UI layout using Bootstrap
- Organized and readable content structure
- Responsive design for better accessibility

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- Bootstrap 5
